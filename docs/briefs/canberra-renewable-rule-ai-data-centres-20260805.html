Canberra readies a renewable-energy rule for AI data centres

The federal government is preparing national rules that would require new AI data centres to run on renewable power rather than gas. The push matters because the boom in server farms is already running into grid limits, state planning rules and the politics of energy prices. Chris Bowen says Canberra should be able to set a national floor even if Queensland and the Northern Territory push back. The next step is whether the legislation can pass without slowing investment or weakening reliability.
