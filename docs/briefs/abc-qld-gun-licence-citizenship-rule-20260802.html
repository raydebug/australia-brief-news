Queensland gun licence applications jump as citizenship checks start

Queensland has begun enforcing a citizenship requirement for gun licences, and police say applications have surged around the change. The rule is meant to tighten eligibility checks, but it may also slow processing while officers verify who qualifies. The next question is whether the system can enforce the new standard without building a long backlog.
